# 🛍️ HomeWork Web 2.1

### Django web application with a product catalog

Учебное веб-приложение на **Django** для работы с каталогом товаров.

Проект демонстрирует базовые возможности Django: модели и ORM, CRUD-операции, шаблоны, management commands, custom template tags и работу с PostgreSQL.

---

## 📌 About the project

Основная часть приложения — каталог товаров.

Проект позволяет работать с товарами и их категориями, отображать каталог через Django templates и управлять данными через backend-приложение.

В проекте также реализованы дополнительные возможности Django, включая собственные template tags и management commands.

## 🎯 Project Purpose

Проект был создан для практики разработки веб-приложений на Django.

Основное внимание уделялось работе с каталогом товаров и освоению стандартных механизмов Django для построения backend-приложения:

**Models → ORM → Forms → Views → Templates**

Дополнительные возможности Django — template tags и management commands — позволили расширить функциональность приложения за пределами базового CRUD.
